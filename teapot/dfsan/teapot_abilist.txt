# Teapot's own DFSan ABI list. Teapot reads it before LLVM's done_abilist.txt
# (vendored unmodified from llvm-project 2249530a922bd19e1a1418c5c6bf1b37ba6c1567,
# compiler-rt/lib/dfsan); a function named here takes only this category.
# A custom function is redirected to the runtime's name__dift_wrapper__ when the
# runtime has one (libcheckpoint src/dift_wrappers); any other custom function is
# treated as discard.

# DFSan's own allocator clears and moves the shadow; Teapot's wrappers do it.

# Not in LLVM's list.
